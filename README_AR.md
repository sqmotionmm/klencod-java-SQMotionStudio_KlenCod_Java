# SQ Motion Studio — Java / KlenCod

هذه نسخة أولية بواجهة Android أصلية مكتوبة بـ Java (بدون WebView للواجهة)، وتحتوي على شاشات: المشاريع، إنشاء مشروع، محرر بمعاينة شبكية وخط زمني، خصائص العناصر، التصدير، والإعدادات.

## فتح المشروع في KlenCod
1. فك ضغط الملف.
2. افتح المجلد الذي يحتوي على `settings.gradle`.
3. نفّذ Gradle Sync ثم `:app:assembleDebug`.

## ملاحظات مهمة
- هذه بداية Java للواجهات وليست نسخة مطابقة أو مكتملة من KeyFlow.
- بعض الأزرار حاليًا واجهات أولية فقط؛ محرك تحرير فعلي، استيراد الوسائط، حفظ المشروع بصيغة `.kf`، والتصدير الحقيقي إلى MP4/PNG ما زالت تحتاج تنفيذًا.
- تم ضبط `compileSdk` على 34 ليتوافق مع إعداد SDK في سير عمل GitHub Actions المرفق.
- لم أتمكن من اختبار البناء في بيئة العمل الحالية بسبب عدم توفر الاتصال لتنزيل Gradle (`UnknownHostException: services.gradle.org`). جرّب البناء من KlenCod أو GitHub Actions، وأرسل سجل الخطأ إن ظهر.
